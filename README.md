# SPC统计分析工具

基于网页的统计过程控制（SPC）分析工具，支持本地数据存储，无需安装数据库。

## 功能特性

### 1. 数据输入
- 支持导入 CSV 文件
- 支持导入 Excel 文件（.xlsx/.xls）
- 数据本地存储（localStorage）

### 2. 控制图类型
| 类型 | 说明 | 适用场景 |
|------|------|----------|
| X-bar R图 | 计量型数据，控制均值和极差 | 连续测量值（长度、温度、重量等） |
| p图 | 计数型数据，控制不合格率 | 样本大小可能不同的不合格率统计 |
| np图 | 计数型数据，控制不合格数 | 样本大小固定的不合格数统计 |

### 3. 统计分析指标
- **过程能力指数**：Cp、Cpk、CPU、CPL
- **过程性能指数**：Pp、Ppk、PPU、PPL
- **控制限**：UCL、LCL、CL

### 4. 异常检测规则
支持 Western Electric 8条判异准则：
1. 1点落在A区之外
2. 连续9点落在中心线同一侧
3. 连续6点单调上升或下降
4. 连续14点交替上下
5. 连续2/3点落在B区之外
6. 连续4/5点落在C区之外
7. 连续15点落在C区之内
8. 连续8点落在C区之外

### 5. 历史数据管理
- 新建/删除项目
- 导出历史数据为Excel
- 项目参数编辑（USL、LSL）

## 使用方法

### 1. 创建项目
1. 点击"新建项目"按钮
2. 输入项目名称
3. 选择数据类型（X-bar R / p / np）
4. 设置规格限（可选，用于Cp/Cpk计算）
5. 点击"创建"

### 2. 导入数据
- 点击"导入CSV"或"导入Excel"按钮
- 数据格式说明：
  - **X-bar R图**：每行一组数据，逗号分隔多个样本
    ```
    10.2, 10.5, 10.3, 10.1
    10.3, 10.4, 10.2, 10.0
    ```
  - **p图**：每行一个子组的不合格数/检验数
    ```
    5, 100
    3, 100
    ```
  - **np图**：每行一个子组的不合格数（样本大小固定）

### 3. 生成分析
1. 点击"📊 生成统计分析" - 查看统计数据和异常报警
2. 点击"📈 生成控制图" - 查看控制图

### 4. 导出数据
- 点击"导出历史"按钮可导出Excel格式的数据

## 文件说明

- `spc_web.html` - 主程序，直接用浏览器打开即可使用
- `spc_app.py` - Python桌面版本（已停止维护）

- HTML5 + CSS3 + JavaScript（原生）
- Chart.js - 图表渲染
- SheetJS (xlsx.full.min.js) - Excel文件处理

## 数据格式说明

### X-bar R图（计量型）
每行是一组（子组），逗号分隔的是这一组的多个测量值。
- 每组至少2个数据
- 建议每组5个数据

### p图（计数型）
每行包含：不合格数, 检验数
- 例如：`5, 100` 表示检验100个，有5个不合格

### np图（计数型）
每行包含：不合格数
- 样本大小n在创建项目时设定

## 注意事项

- 数据存储在浏览器本地，清除浏览器数据会丢失
- 建议定期导出重要数据
- Cp/Cpk计算需要设置USL和LSL规格限
